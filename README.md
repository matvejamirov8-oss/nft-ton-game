# 💎 Gifts Market — Telegram-style TON gift trading game

Игра-симулятор рынка подарков NFT за TON с интерфейсом в стиле Telegram.

**Играть:** https://matvejamirov8-oss.github.io/nft-ton-game/

## Что внутри

- **💬 Чаты** — живой список чатов как в Telegram: продавцы, коллекционеры, покупатели твоих лотов. Непрочитанные, галочки ✓/✓✓, индикатор «печатает…».
- **🛍 Маркет** — лоты продавцов. Открой чат → сбивай цену, проси скидку, покупай. Обидишь низкой ценой — продавец разозлится и поднимет цену.
- **🎁 Подарки** — подарки других людей. Нажми на человека → открывается чат: покупай его подарки, болтай, дари свои, растите дружбу. Друзья делают скидки.
- **💰 Продажи** — выставляй свои подарки, веди переговоры с покупателями в чате, комиссия маркетплейса 5%.
- **👤 Профиль** — инвентарь, статистика, тренд рынка.

## Механики

- Каждый час: +4 TON бонуса (кнопка в шапке)
- Рынок живёт: тренд колеблется каждые 5 секунд, цены дышат, новые лоты появляются
- Дружба с коллекционерами растёт от подарков → скидки до ~20% и подарки в ответ
- Мгновенная скупка за 70% если надо продать быстро

Чистый ванильный HTML/CSS/JS, без сборки. Картинки подарков и аватарки генерируются как инлайн-SVG.
