# 💎 TON NFT Маркет — игра

Мобильная (в стиле Telegram Mini App) игра про рынок NFT-подарков и покупку за TON. Чистый HTML/CSS/JS — без зависимостей и сборки.

## Запуск

Открой `index.html` в браузере (или `npx serve .`) — прогресс сохраняется в localStorage.

## Что есть в игре

### 🛒 Маркет
- 13 подарков 4 редкостей (обычный → легенда: от Леденца до Короны Дурова)
- 6 продавцов с разной жадностью, цены двигаются вместе с трендом рынка
- Покупка сразу по цене или через **чат с продавцом**

### 💬 Чаты с продавцами (торг)
- Предлагай свою цену текстом («дам 12») или кнопкой «Предложить»
- Продавец принимает, сбивает цену, а от наглых оферов **повышает** цену
- У каждого продавца свой «пол» скидки: торговаться с Шулером Олегом сложнее, чем с Аней
- «Насколько уступишь?» — разовая мягкая скидка за вежливость
- После согласия появляется кнопка покупки по согласованной цене

### 🎁 Подарки людей
- Вкладка-лента людей с их подарками и шкалой дружбы
- Клик по человеку → **чат с ним**
- В чате: спроси про любой его подарок → он назовёт цену → торгуйся и покупай у него напрямую
- Даруй свои подарки — растёт дружба, друзья дают скидки и присылают ответные подарки

### 🏷 Продажи
- Выставляй свои подарки по своей цене
- Живые покупатели постоянно пишут в чат со своими предложениями
- Принимай предложение, контрпредлагай свою сумму (у покупателя есть потолок) или отказывай
- Комиссия маркетплейса 5%, в «Кассе» — заработано/потрачено

### 💬 Чаты
- Единый список всех бесед с непрочитанными и бейджами на вкладках

### 🎒 Мои
- Инвентарь с P/L по каждому подарку относительно рынка
- «Скупка» — мгновенная продажа за 70% цены, «Выставить» — на свой лот
- Статистика: сделки, капитал, профит

### Ещё
- 🎁 Бонус +4 TON каждую минуту (двойной клик по кнопке бонуса + «СБРОС» — начать заново)
- Уровни от «Новичка рынка» до «Крипто-легенды»
- Автосохранение прогресса
